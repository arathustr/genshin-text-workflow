# 正文出处格式

正文出处写给普通读者看，像书籍章节目或圣经典故一样，不写内部数据表。

## 推荐格式

角色故事：

```text
——《原神》·赛诺·角色故事
```

角色语音：

```text
——《原神》·雷电将军·角色语音
```

任务对话，有任务名和说话人：

```text
——《原神》·魔神任务「流转存续的花神诞祭」·纳西妲
```

任务对话，有任务名但说话人不明：

```text
——《原神》·任务「流转存续的花神诞祭」·对话
```

NPC 对话，有说话人但任务名不明：

```text
——《原神》·妮维妲·对话
```

书籍：

```text
——《原神》·书籍「白之公主与六侏儒」
```

道具、材料、图鉴：

```text
——《原神》·素材图鉴「「自由」的教导」
```

圣遗物：

```text
——《原神》·圣遗物「如雷的盛怒」
```

武器：

```text
——《原神》·武器「西风剑」
```

加载、探索、系统提示：

```text
——《原神》·加载界面提示
——《原神》·世界探索提示
```

## 禁止进入正文的格式

这些只用于内部核验，不给读者看：

```text
FetterStoryExcelConfigData.json
Avatar ID 10000071
TextMap hash 605580384
Dialog ID 30090924
talkContentTextMapHash
```

若只能写出这类出处，换一条引文。
